# TRT Minecart

**T**unneling - **R**oadbed - **T**rack

Turn minecarts into automated machines for tunneling, roadbed construction, and track laying.

## Features

![Container](/assets/Container.webp)

### Tunneling

Place pickaxes in the hopper minecart. It will attempt to mine a 3 × 3 area in the direction of travel. Block drops follow the properties of the pickaxe.

### Roadbed Laying

Place blocks in the hopper minecart. It will lay them in a 3-block-wide path in the direction of travel.

### Track Laying

Place rails in the hopper minecart. When the minecart is about to leave the existing track, it will place rails beneath itself to extend the track.

### Independent Features

The features are independent of each other. You can enable only the features you need.

### Recommended Item Order

To control the execution order, place items as follows:

**Pickaxes** -> **Blocks** -> **Rails**

* Pickaxes first for **tunneling**.
* Blocks in the middle for **roadbed laying**.
* Rails last for **track laying**.
